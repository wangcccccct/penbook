# Security Policy

## Reporting a vulnerability

Please do not report security issues in public issues. Use GitHub's **Report a vulnerability** feature on the repository's Security tab to send a private advisory to the maintainers. Include the affected version, platform, steps to reproduce, and likely impact. Do not include private notebooks or other personal data.

If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and ask for a private reporting channel.

## Supported versions

Security fixes are provided for the latest published version. Please update before reporting an issue when possible.
